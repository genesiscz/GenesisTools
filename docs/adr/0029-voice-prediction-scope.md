# Use global prediction and explicit scope for voice corrections

A person can appear in several projects. Prediction uses all eligible, compatible prints by default and can be
restricted to a project. Browsing, playback, bulk actions and Undo honor the selected meeting, project or global
scope. Pin a legacy project-local number to its sample ID or revision at preview. Applying the prediction
setting to removal could delete another project's clip.
