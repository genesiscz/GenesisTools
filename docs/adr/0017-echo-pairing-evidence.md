# Require evidence across reference meetings before pairing echoes

After calibration, measure echo in loud owner windows across five reference meetings. Build the low-priority
pairer only if more than 2% of owner lines in at least one meeting show echo. Otherwise retain the independent
turns. Any pairing must keep the source line IDs, separate two actual speakers and recognize a synthetic echo.
Matching short words and timing alone could merge two people.

Measured 2026-11-19: 0 of 2,414 loud owner lines in the five reference meetings show echo (highest mic-to-call
correlation 0.565). The pairer is not built, and both turns stay independent.
