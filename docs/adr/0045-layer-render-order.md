# Draw the layer stack at the camera's existing position

Preview and export traverse the same bottom-to-top order above text and the speed badge, below the cursor and
progress bar. Without a stored order the camera keeps its existing position, with additional media in file
order. A separate export stack or moving the overlays across the cursor would change how an existing project
looks.
