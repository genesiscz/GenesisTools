# Use explicit mute counts as a seat editor hint

Show the fraction of valid, explicit mute lists during the person's call stay. The optional high-mute hint needs
at least 80%, a nonzero denominator and no reliable unmuted speaking observation. A missing read contributes
nothing. A saved seat takes precedence. Assigning a seat from the roster or mute count alone would put a quiet
remote and a muted room guest in the same place.
