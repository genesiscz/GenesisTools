# Route every permanent voice attachment through one locked insert

An individual human answer or explicit confirmation in a meeting with a project can teach the library. Every
path that attaches a print, including move, backfill and receipt restoration, checks current ownership, source
eligibility and refusals under the writer lock. Wrong-person blocks one binding. Bad or mixed audio blocks the
source for everyone. Plain remove permits eligible recovery. Checking only the original writer would let a retry
restore a rejected clip.
