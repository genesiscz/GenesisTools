# Run voice naming again after a print is published

A published print can change which name the normal voice pass proposes in that meeting. Schedule that pass once
per meeting, coalescing publications over the configurable delay of 10 seconds by default. It emits ordinary
suggestions with the voice reason and preserves decided items. Running on every answer before publication could
score the old library or repeat the same work.
