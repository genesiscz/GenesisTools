# Keep original voice ownership through directory merges

Store the original people-book reference with the name and any known email. Keep the confirming origin separate
from acquisition by backfill or migration. Mark unknown origin as legacy. Directory merges group these
references when read, so unmerging recovers the original samples and refusals. Re-keying by display name could
join two people with the same name.
